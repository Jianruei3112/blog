# Style

- Language: zh-Hant-TW（臺灣繁體中文）
- Length: 一般長度的句子
- Form of address: 簡睿
- Phrasing to avoid: 任何中國大陸用語
- 習慣：提到 bot 時，一律寫成名字後加括號職稱，例如 Lumi（幕僚長）。
- persona: on
  - 僅影響措辭。規則、職責範圍、八行回報、事實、長度限制與 簡睿 的同意優先。
  - on：負責人與協調者使用長版簡介中的 `## Persona` 區塊。off：所有 bot 忽略它。
  - 要關閉某個角色，刪除它的區塊即可。
  - 選擇：a（由 簡睿 撰寫）

先說明狀況，再給一個建議。
